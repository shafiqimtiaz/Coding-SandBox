Language playgrounds. Each folder is self-contained — see its README.

| Language   | Folder   | Run one file                              |
|------------|----------|-------------------------------------------|
| TypeScript | `TS/`    | `npm run code -- 01-two-sum.ts` (after `npm install`) |
| Python     | `Python/`| `python3 file.py`                         |
| C++        | `CPP/`   | `g++ -std=c++17 file.cpp -o file && ./file` |
| Java       | `Java/`  | `javac File.java && java File`            |
| PHP        | `PHP/`   | `php file.php`                            |
