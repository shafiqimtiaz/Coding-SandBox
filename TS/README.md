# TypeScript Practice

Interview problems as runnable single files, numbered by priority (`00` essentials, `01`–`10` must-know, `11`–`17` very useful, `18`–`22` extras).

Setup once:

```sh
npm install
```

Pick a file from a list, or run one directly (`--` optional), typecheck everything:

```sh
npm run code
npm run code 01-two-sum.ts
npm run compile
```
